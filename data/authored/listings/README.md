# data/authored/listings/

One file per provider, `<provider>.yaml`: what providers.dev states of the provider's model list (an authored list,
fields of its models), each statement with a reason and evidence. The README of the repository says how, under
"State what a provider's model list holds". `openai-codex.yaml` holds the Codex login's list until the discovery publishes Codex's own. `devin.yaml` and
`claude-subscription.yaml` state the release dates (`released`) of listed models that have no entry, each from the
lab's own source; the README of the repository says how, under "Release dates".
